# Yahoo Fantasy Football Assistant

A personal, read-only fantasy football assistant for one user.

This project will connect my Yahoo Fantasy Football account to
ChatGPT through an MCP server to help evaluate lineups, available
players, waiver pickups, and potential trades.

## Data requested

- My team's roster and other rosters in leagues I belong to
- Free agents and waiver availability
- Player statistics
- League scoring settings, standings, and matchups

## Intended use

This is an individual personal project, not a company or public
commercial service. It is currently in development, pending Yahoo
API approval. It will not submit trades or make roster changes.

Fantasy data provided by [Yahoo Fantasy](https://football.fantasysports.yahoo.com/).
